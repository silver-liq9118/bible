# 오늘의 성경 토스 미니앱 개인정보처리방침 준비 문서

인앱 `정보 → 개인정보처리방침`과 함께 확인할 **출시 전 초안**입니다. 시행 예정일 2026-09-07은 실제 출시일에 맞춰 갱신하세요. Flutter 앱의 AdMob 방침과 구별합니다.

## 데이터 처리

- 이름·연락처·토스 계정 정보를 요청하지 않으며 별도 회원가입·광고·분석·결제 서버가 없습니다.
- 즐겨찾기 구절 ID와 글자 크기를 기기 localStorage에 보관하며 운영자 서버로 전송하지 않습니다. 초기화 또는 미니앱 데이터 삭제까지 보관하며 기기/토스 정책에 따라 먼저 삭제될 수도 있습니다.
- 공유 버튼을 누르면 선택 구절과 성경 위치를 토스/OS 공유 기능에 전달합니다. 수신 앱은 사용자가 선택합니다. 복사하면 동일한 내용을 클립보드에 씁니다. 수신 서비스·토스 플랫폼의 처리는 각 서비스 방침을 따릅니다.
- 정보 화면의 ‘저장한 정보 초기화’로 삭제할 수 있습니다. 기기 간 동기화·서버 복구는 제공하지 않습니다.
- 문의: **sonprojecta@gmail.com** (기존 저장소 README의 문의처). 토스 더보기의 문의하기도 작동하도록 콘솔 고객센터를 설정해야 합니다.
- 처리 방식 변경 시 인앱·공개 방침과 시행일을 함께 갱신합니다.

## 게시 전 확인

1. 법적 운영자명, 개인정보 담당자/연락처, 문의 주소를 확정하고 인앱에도 반영합니다. 기존 `info.dart`의 Goodtooday Co.만으로 현재 법적 운영자임을 단정하지 않았습니다.
2. 토스 플랫폼 자체 처리와 앱 운영자 처리를 구별해 실제 구성에 맞게 검토합니다.
3. 콘솔이 요구하는 공개 HTTPS URL에 최종 방침을 게시·등록합니다. 이 Markdown이나 개발 서버 URL을 그대로 등록하지 않습니다.
4. 현재 설명은 이번 미니앱 코드 기준입니다. 로그인·광고·분석·결제를 추가하면 방침과 동의/삭제 흐름을 재검토합니다.
